# Self-Improving Agent Framework

**Purpose:** Continuous improvement for all agents in the workforce

---

## Core Principles

1. **Weekly Review** — Every agent evaluates their performance
2. **Learn from Mistakes** — Document failures, fix root causes
3. **Optimize Workflows** — Automate repetitive tasks
4. **Knowledge Sharing** — Update shared memory after learnings

---

## Agent Review Protocol

### Weekly (Sunday night)
Each agent should:
1. Review messages/tasks from past week
2. Identify: What worked? What failed? What was inefficient?
3. Update `/memory/agent-improvements.md` with findings
4. Propose changes to prompts, workflows, or tools

### Daily (end of day)
- Log key learnings to `/memory/daily-learnings.md`
- Note: "If I did X differently, I'd save Y time"

---

## Improvement Categories

| Category | Examples |
|---|---|
| **Prompting** | Better instructions, clearer context |
| **Automation** | Tasks that should be scripted |
| **Memory** | Info that should be captured |
| **Tools** | Missing capabilities needed |
| **Workflows** | Bottlenecks or redundant steps |

---

## Reporting

- **Weekly:** Aggregate improvements into actionable changes
- **Morning Report:** Include "What I improved" section
- **Agent Updates:** Modify AGENTS.md or skill docs when processes change
