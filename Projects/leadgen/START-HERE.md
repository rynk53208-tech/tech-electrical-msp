## ❓ Common Questions

**Q: Do I need to code?**  
A: No! You can change company name, colors, contact info without touching code. For server setup, follow the guides.

**Q: How do I capture leads?**  
A: Built-in! Form saves to browser storage (static) or Node.js server (if you run it). See deployment options for email integration.

**Q: Is it mobile-friendly?**  
A: Yes! 100% responsive. Works on phones, tablets, desktops.

**Q: Can I add my logo?**  
A: Yes! Edit index.html and add an `<img>` tag in the hero section. Replace the text header with an image.

**Q: How do I add more services?**  
A: Find a `.service-card` block in index.html, copy it, paste it, edit the text and emoji icon.

**Q: What's the cheapest way to deploy?**  
A: Netlify or Vercel (both free tier). Just drag index.html to their interface. Takes 2 minutes.

**Q: Can I use my own domain?**  
A: Yes! All hosting platforms support custom domains. See DEPLOYMENT.md.

**Q: What if I want to change the colors?**  
A: Search for `#1e3a8a` (primary) and `#fbbf24` (accent) in index.html and replace with your brand colors.

**Q: How do I get email notifications when someone submits?**  
A: See DEPLOYMENT.md for Zapier, Nodemailer, or Google Sheets integration options.
