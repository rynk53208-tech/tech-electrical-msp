# Technical FAQ

Answers to common questions about our tech support services.

---

## 1. How does remote support work?

Remote support lets us fix most issues without visiting your location. We use secure, enterprise-grade tools to connect to your computer or network remotely.

**What you need:**
- Internet connection
- Ability to grant remote access (we'll guide you through it)

**How it works:**
1. You reach out describing the issue
2. We send a link or have you download our remote support tool
3. You approve the connection (you see exactly what's happening)
4. We diagnose and fix the problem in real-time
5. You verify everything works before we disconnect

**Security:** Connections are encrypted end-to-end. We can only see what you share during the session. Once disconnected, we have no ongoing access.

**What can be handled remotely:**
- Software troubleshooting and fixes
- System configuration
- Virus/malware removal
- Email and account setup
- Network troubleshooting (some cases)
- Performance optimization

**When on-site is needed:** Hardware replacements, physical network wiring, some server issues.

## 3. How quickly do you respond?

| Issue Priority | Response Time |
|----------------|---------------|
| Critical/Emergency (system down, security breach, data loss) | Within 1 hour |
| Urgent (significant business impact) | Same business day |
| Standard (non-blocking issues) | Within 24 hours |
| General inquiries | Within 48 hours |

**What counts as critical:**
- Complete network outage
- All computers down
- Security breach or ransomware
- Phone system down (if business-dependent)
- Active data loss

**What counts as urgent:**
- Single computer won't start
- Major software故障
- Printer/network issues affecting multiple people

**Standard issues:** Password resets, minor software glitches, general questions.

We keep you updated on ETA once we assess the issue. You'll never be left wondering about status.
