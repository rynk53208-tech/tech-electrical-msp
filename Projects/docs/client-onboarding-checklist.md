# Client Onboarding Checklist

For Irvin's Tech & Electrical Services Business

---

## Day 1 Tasks

### Pre-Meeting Preparation
- [ ] Review client intake form and service request details
- [ ] Verify client contact information (phone, email, company if applicable)
- [ ] Pull any existing client history if returning client
- [ ] Prepare quote/estimate based on initial assessment

### Initial Contact
- [ ] Send welcome email with estimated arrival time and technician name
- [ ] Confirm scope of work and any special requirements
- [ ] Note access codes, parking instructions, or building protocols

### Service Delivery
- [ ] Arrive on time or notify client of any delays
- [ ] Verify identity and confirm authorized contact
- [ ] Perform diagnostic assessment
- [ ] Provide real-time updates on findings
- [ ] Complete work per agreed scope
- [ ] Test all repairs/solutions before wrapping up

### End of Day 1
- [ ] Review warranty terms with client
- [ ] Schedule follow-up if needed
- [ ] Collect payment or confirm billing timeline
- [ ] Ask for referral or review if satisfied with service

---

## Week 1 Tasks

### Follow-Up
- [ ] Send Day 1 thank-you message/email
- [ ] Check in within 24-48 hours to ensure everything is working
- [ ] Address any issues reported by client

### Administrative
- [ ] Create or update client profile in CRM/database
- [ ] File all documentation (quotes, invoices, photos, notes)
- [ ] Process payment if not collected on Day 1
- [ ] Send official invoice with payment terms

### Relationship Building
- [ ] Add client to appropriate communication list
- [ ] Note any future service needs mentioned during appointment
- [ ] Add to follow-up calendar for proactive outreach

---

## Month 1 Tasks

### Check-In
- [ ] Reach out at 2-week mark for service satisfaction check
- [ ] Reach out at 1-month mark with maintenance reminder or next-step suggestions

### Upsell / Retainer Opportunities
- [ ] Present maintenance plan if applicable (MSP/MSSP clients)
- [ ] Discuss future projects or recurring services
- [ ] Offer add-on services based on their setup

### Feedback & Reviews
- [ ] Request Google review or testimonial
- [ ] Ask for referrals to friends/family/colleagues
- [ ] Document any feedback for service improvement

---

## Documentation Requirements

### Client File (Physical or Digital)
- [ ] Signed service agreement / T&C
- [ ] Intake form with contact details and service history
- [ ] Scope of work document
- [ ] Before/after photos (hardware repairs, network setups, etc.)
- [ ] Quote/estimate with pricing breakdown
- [ ] Invoice and payment record
- [ ] Warranty documentation
- [ ] Any special instructions or access details

### Internal Records
- [ ] Entry in CRM/database (client name, contact, services rendered, next follow-up)
- [ ] Notes on client preferences or recurring issues
- [ ] Equipment serial numbers / licenses documented
- [ ] Network diagrams or system maps (if applicable)

### Compliance
- [ ] Data handling acknowledgment (if handling sensitive client data)
- [ ] Insurance/liability waiver on file
- [ ] NDAs signed if applicable (commercial clients)

## Quick Reference Card

| Phase | Key Actions |
|-------|-------------|
| **Day 1** | Show up, diagnose, fix, collect payment, schedule follow-up |
| **Week 1** | Follow up, file docs, send invoice, process payment |
| **Month 1** | Check in, present maintenance plan, ask for reviews/referrals |
| **Always** | Document everything, protect client data, deliver value |
