# Onsite Service Checklist

Professional checklist for tech service calls. Use this for every onsite visit.

---

## 🏠 Before Leaving Office

- [ ] Confirm client name, address, and contact phone number
- [ ] Review ticket/issue details and notes
- [ ] Gather all required tools and equipment
  - Laptop/tablet with remote access tools
  - USB drives, cables, adapters (HDMI, USB-C, Ethernet)
  - Screwdriver set (precision + standard)
  - Anti-static wrist strap
  - Flashlight/headlamp
  - Multimeter
  - Thermal paste (if needed)
  - Cleaning supplies
  - Spare parts (if specific parts ordered)
- [ ] Charge all devices and batteries
- [ ] Print or download any relevant documentation/manuals
- [ ] Check vehicle fuel/traffic conditions
- [ ] Inform office of departure time and ETA
- [ ] Bring business cards and receipt forms

---

## 🚗 Arrival at Client

- [ ] Park professionally (not blocking driveway if possible)
- [ ] Text or call client upon arrival
- [ ] Wait for acknowledgment before approaching
- [ ] Greet client professionally, introduce yourself
- [ ] Ask where to set up/work
- [ ] Put on boot covers or remove shoes if required
- [ ] Do a quick walkthrough: confirm the issue before starting
- [ ] Ask about any access codes, Wi-Fi credentials, or pet restrictions

---

## 🔧 During Service

- [ ] Take photos of existing setup/wiring before touching anything
- [ ] Keep client informed of progress and findings
- [ ] Document any new issues discovered
- [ ] Ask permission before making changes beyond scope
- [ ] Keep workspace clean — no tools left scattered
- [ ] Label any cables/disconnects
- [ ] Test incrementally — don't assemble until verified
- [ ] Run diagnostics and verify fix works
- [ ] Update client on final status and any recommendations

---

## 👋 Before Leaving

- [ ] Clean up workspace, dispose of packaging
- [ ] Restore any furniture/items moved
- [ ] Show client the completed work
- [ ] Demonstrate the fix and explain what was done
- [ ] Provide verbal/written recommendations for future
- [ ] Collect payment or confirm billing (if applicable)
- [ ] Get signature on service receipt
- [ ] Offer business card for referrals
- [ ] Thank the client by name

---

## 🏢 After Returning

- [ ] Log arrival/departure times in ticket system
- [ ] Update ticket with work performed and parts used
- [ ] Note any follow-up needed
- [ ] Submit expense reports if applicable
- [ ] Restock used tools/supplies
- [ ] Charge any depleted equipment
- [ ] Schedule follow-up if promised
- [ ] File any warranty claims for parts

---

## 💡 Pro Tips

- **Always** photograph before/after — protects you and helps future troubleshooting
- **Never** leave a job unfinished without client acknowledgment
- **Keep** a spare kit in vehicle for unexpected needs
- **Document** everything — your reputation is built on clarity
