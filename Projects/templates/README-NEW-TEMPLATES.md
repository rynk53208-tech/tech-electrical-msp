# Tech & Electrical Services LLC - Templates

## New Professional Templates (March 2026)

Three new HTML templates have been created for professional client-facing documents:

### 1. **invoice.html**
Professional invoice template for billing clients.

**Features:**
- Company header with logo placeholder
- Client and service location billing info
- Itemized service line items with quantities, rates, and amounts
- Automatic calculations for subtotal, tax, and total
- Payment terms section with multiple payment methods
- Professional styling with color scheme (Blue: #0066cc)
- Print-friendly design
- Status badges (Outstanding, Paid, etc.)

**When to use:**
- Billing for completed services
- MSP monthly invoicing
- Repair job billing
- Electrical services billing

**Placeholders to fill:**
- [INV-2026-0001] → Invoice number
- [DATE] → Invoice date
- [DUE_DATE] → Payment due date
- [CLIENT_NAME], [COMPANY_NAME], [ADDRESS] → Client info
- [SERVICE DESCRIPTION 1-3] → Service items
- [QTY], [RATE], [AMOUNT] → Line item details
- [SUBTOTAL], [TAX], [DISCOUNT], [TOTAL] → Financial totals

## How to Use These Templates

### Quick Start:
1. Open the HTML file in a web browser
2. Use your browser's Find & Replace (Ctrl+H) to swap placeholders:
   - Replace `[CLIENT_NAME]` with actual client name
   - Replace `[DATE]` with actual date
   - etc.
3. Print to PDF or send directly via email
4. Have client sign the service agreement digitally or physically

### Customization:
Each template uses professional CSS styling. You can:
- **Change colors**: Search for color codes (#0066cc, #2196F3, #d32f2f) and replace
- **Adjust fonts**: Modify `font-family` in the `<style>` section
- **Add real logo**: Replace the `Logo` placeholder div with an `<img>` tag
- **Modify payment terms**: Edit the payment terms sections

### Digital Workflow:
- **Email**: Send the HTML file directly - most email clients render it beautifully
- **PDF**: Print to PDF in any browser for archival
- **Digital Signatures**: Use tools like DocuSign, PandaDoc, or Adobe Sign to add e-signatures
- **Edit**: Open in any text editor to customize before sharing
