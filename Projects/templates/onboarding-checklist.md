# New Client Onboarding Checklist — MSP

**Purpose:** Ensure consistent onboarding for every new MSP client.

---

## 📋 PHASE 1: PRE-ONBOARDING (Before Day 1)

### Contract & Paperwork
- [ ] Signed MSA/Service Agreement
- [ ] Signed NDA (if needed)
- [ ] Completed Client Intake Form
- [ ] Payment method on file (or credit approval)
- [ ] Insurance certificate received (if required)

### Account Setup
- [ ] Create client account in CRM
- [ ] Set up client folder in Google Drive/Dropbox
- [ ] Create client folder for documentation
- [ ] Add to monthly billing schedule
- [ ] Set up client portal access (if applicable)

---

## 📋 PHASE 2: DISCOVERY & ASSESSMENT (Day 1-3)

### Initial Meeting
- [ ] Walkthrough of all locations
- [ ] Meet key contacts (owners, managers, power users)
- [ ] Document all current equipment
- [ ] Get network diagram (or create one)
- [ ] Collect login credentials (securely)
- [ ] Take photos of equipment/ rack layout

### Technical Assessment
- [ ] Run network discovery scan
- [ ] Check server/workstation health
- [ ] Review backup status
- [ ] Check antivirus/Security software
- [ ] Document bandwidth/ISP details
- [ ] Check UPS battery status
- [ ] Review existing contracts (ISP, software, etc.)

### Deliver Discovery Report
- [ ] Send to client with findings
- [ ] Highlight immediate risks
- [ ] Propose quick wins

---

## 📋 PHASE 3: SETUP & CONFIGURATION (Day 3-7)

### Remote Access
- [ ] Install RMM agent on all devices
- [ ] Configure remote access (VPN or remote desktop)
- [ ] Test all connections

### Monitoring
- [ ] Add servers to monitoring
- [ ] Add workstations to monitoring
- [ ] Configure alert thresholds
- [ ] Set up uptime checks
- [ ] Configure backup monitoring

### Security
- [ ] Enable Windows Firewall on all machines
- [ ] Verify antivirus is installed/updated
- [ ] Configure Windows Update policies
- [ ] Set up password policy
- [ ] Enable BitLocker (if needed)
- [ ] Configure 2FA on admin accounts

### Documentation
- [ ] Update network diagram
- [ ] Document all credentials (securely)
- [ ] Create client IT handbook
- [ ] Take updated photos

### Client Setup
- [ ] Create email accounts (if handling)
- [ ] Set up shared drives/folders
- [ ] Configure printers/network devices
- [ ] Set up spam filter
- [ ] Configure mobile devices (if applicable)

---

## 📋 PHASE 4: TRAINING & HANDOVER (Day 7-14)

### Client Training
- [ ] Train on how to submit tickets
- [ ] Show how to reach support
- [ ] Review acceptable use policy
- [ ] Demonstrate remote support (optional)

### First Support Contact
- [ ] First ticket resolved
- [ ] Document response time

### Documentation Delivery
- [ ] Send IT Handbook to client
- [ ] Review emergency contacts
- [ ] Explain escalation process

---

## 📋 PHASE 5: 30-DAY CHECK-IN

- [ ] 30-day check-in call
- [ ] Review any issues from first month
- [ ] Gather feedback
- [ ] Confirm satisfaction
- [ ] Ask for referral/review
