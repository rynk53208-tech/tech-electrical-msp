## 1. Power Infrastructure

### UPS (Uninterruptible Power Supply) Installation
- **What it is:** Battery backup for servers, network gear, workstations
- **IT client's pain:** Power outages corrupt data, cause downtime, kill productivity
- **Typical scope:**
  - Desktop UPS (APC Back-UPS, CyberPower) — 1-3kVA
  - Rack-mount UPS (APC Smart-UPS, Eaton) — 3-10kVA for server rooms
  - Network UPS (APC Smart-UPS with network card) — for remote monitoring
- **Value-add:** Integrate with existing infrastructure, configure shutdown scripts, set up monitoring

### PDU (Power Distribution Unit) Installation
- **What it is:** Rack-mounted power distribution with monitoring
- **IT client's pain:** Can't see power usage, can't control outlets remotely
- **Typical scope:**
  - Basic PDU (metered)
  - Intelligent PDU (-switched, with remote on/off)
  - ATS PDU (automatic transfer switch for redundancy)
- **Value-add:** Align with UPS capacity, map circuits to server/power needs

### Circuit Installation / Upgrade
- **What it is:** New 20A/30A/50A circuits for server rooms, panels
- **IT client's pain:** "We need more power but the panel is full" / "The circuit keeps tripping"
- **Typical scope:**
  - 20A circuit for patch panels, switches
  - 30A dedicated circuit for server rack
  - 50A circuit for UPS, PDU, cooling equipment
- **Value-add:** Coordinate with landlord/building management, pull permits, label clearly

## 2. Climate Control

### HVAC Controls for Server Rooms
- **What it is:** Temperature/humidity monitoring, AC integration, alerts
- **IT client's pain:** Server room overheating = downtime
- **Typical scope:**
  - Temp/humidity sensors (APC, Raritan, ServerTech)
  - Alert thresholds (e.g., >78°F = page someone)
  - Integration with building HVAC or standalone AC unit
  - Cooling failure detection and automated shutdown
- **Value-add:** Connect to existing BMS or create standalone monitoring solution

### Precision Cooling Solutions
- **What it is:** In-row or in-room AC units for data centers
- **IT client's pain:** "The AC can't keep up and we're adding servers"
- **Typical scope:**
  - Small footprint AC (2-5 ton) for closet/small room
  - Rack-based cooling (Coolter, etc.)
  - Exhaust ducting, condensate management
- **Value-add:** Size correctly for heat load, integrate with UPS for graceful shutdown on AC failure

## 3. Data Center / Utility Room Electrical

### Dedicated Panel Installation
- **What it is:** Sub-panel fed from main, dedicated to IT/electrical loads
- **IT client's pain:** No dedicated power, constantly tripping breakers
- **Value-add:** Proper sizing, clearly labeled, future-proofed for expansion

### Generator / Emergency Power Connection
- **What it is:** Transfer switch, generator hookup, ATS integration
- **IT client's pain:** "When the power goes out, we lose everything"
- **Typical scope:**
  - Manual or automatic transfer switch
  - Generator interconnection (portable or standby)
  - Circuit prioritization (what stays on, what shuts down)
- **Value-add:** MSP can manage the IT side; we handle the electrical hookup and safety

### Grounding & Bonding
- **What it is:** Proper grounding for server racks, equipment, telecom
- **IT client's pain:** "We got a shock from the rack" / equipment keeps dying
- **Value-add:** Bring old buildings up to code, eliminate ground loops

## 4. Power Conditioning & Protection

### Surge Protection
- **What it is:** Whole-building or panel-level surge suppression
- **IT client's pain:** Power spikes fry equipment
- **Value-add:** Install at service entrance + point-of-use for critical gear

### Power Conditioning / Voltage Regulation
- **What it is:** Automatic voltage regulator (AVR), line conditioner
- **IT client's pain:** Brownouts, voltage sags, dirty power
- **Typical scope:** For areas with unstable grid power

### Cable Management
- **What it is:** Organized, labeled, fire-rated cable runs
- **IT client's pain:** "I can't trace which cable goes where"
- **Value-add:** Clean installs, documentation, future-proofing
