## 1. How to Evaluate Vendors

### Initial Screening Criteria

| Category | Must Have | Nice to Have |
|----------|-----------|--------------|
| **Legal** | Licensed, insured, bonded | E&O insurance |
| **Financial** | Payment terms that work for cash flow | Net-30+ terms, volume discounts |
| **Technical** | Meets specs for your use case | Certifications, 24/7 support |
| **Reputation** | References available | Industry awards, case studies |

### Evaluation Steps

1. **Identify the need** — What problem is this vendor solving? Is it replaceable?
2. **Market scan** — Get 2-3 quotes minimum. Don't sleep with one vendor.
3. **Background check** — 
   - Search for complaints (BBB, Google Reviews, industry forums)
   - Verify license/insurance (if applicable)
   - Ask for 2-3 references (actually call them)
4. **Trial run** — For new vendors, start small. One project. One month. Proof of concept.
5. **Risk assessment** — What happens if this vendor disappears tomorrow? Do you have a backup?

### Decision Framework

```
Score each vendor 1-5 on:
- Price competitiveness
- Reliability / uptime
- Communication / responsiveness
- Quality of work/product
- Scalability

Weighted total = Decision basis
```

## 2. What to Look For

### For IT/Tech Vendors (Hardware, Software, Cloud)

- **Support responsiveness** — How fast do they actually respond? Test it before committing.
- **SLAs** — Get them in writing. Know what "24/7 support" actually means.
- **Security posture** — Do they have SOC 2, ISO 27001? What's their data handling policy?
- **Exit terms** — Can you get your data out? What's the migration path?
- **Upgrade path** — Are you buying yesterday's tech?

### For Service Vendors (Subcontractors, Electricians, etc.)

- **Safety record** — OSHA incident history, worker compensation status
- **Scope clarity** — Get detailed SOWs. Ambiguity = cost overruns.
- **Timeline track record** — Have they hit deadlines before?
- **Communication style** — Do they update you proactively or only when asked?
- **Subcontractor use** — Who's actually doing the work? Vet them too.

### Red Flags

- No written contracts or vague SOWs
- Pricing that seems too good (it's usually not)
- Reluctant to provide references
- High turnover (ask how long their techs have been there)
- "We've always done it this way" — no interest in improvement

## 3. Review Schedule

### Frequency Matrix

| Vendor Type | Review Frequency | Full Audit |
|-------------|------------------|------------|
| **Critical** (affects client delivery, core infrastructure) | Monthly | Quarterly |
| **Standard** (regular supplies, routine services) | Quarterly | Annually |
| **Occasional** (one-off projects, emergency vendors) | Post-project | N/A |

### Monthly Check-in (Critical Vendors)

- Review SLA compliance (tickets, response times, uptime)
- Check for price changes or term updates
- Flag any issues observed

### Quarterly Review (All Active Vendors)

- Scorecard update (see Section 4)
- Budget vs. actual spend
- Renewals coming up in next 90 days
- Competitive market check — are there better options?

### Annual Audit (Critical Vendors)

- Full contract review and renegotiation
- Deep dive on total cost of ownership
- Reference re-verification
- Strategic fit assessment — is this vendor still right for where the business is going?

## 4. Performance Metrics

### General Metrics (All Vendors)

| Metric | Target | Escalation |
|--------|--------|------------|
| **On-time delivery** | ≥95% | <90% = warning |
| **Invoice accuracy** | 100% | Any dispute >1x = review |
| **Response time** | Per SLA (typically <4hr for critical) | Breaches = documented |
| **Quality score** | 4+/5 from internal team | <3.5 = discussion |
| **Safety incidents** | 0 | Any = immediate review |

### Category-Specific Metrics

**Hardware Vendors:**
- Defective rate (<2%)
- Warranty claim processing time
- Stock availability / lead times

**Software/SaaS:**
- Uptime (≥99.9%)
- Feature delivery vs. roadmap
- API stability / breaking changes

**Service Subcontractors:**
- First-time fix rate
- Client satisfaction (post-job survey score)
- Job completion within estimate ±15%

**Electrical:**
- Permit/code compliance rate
- Inspection pass rate
- Job site professionalism

## Quick Reference

**Golden Rules:**
1. Never marry a vendor — always know your backup
2. Get everything in writing
3. Test support before you need it
4. Review proactively, not just when things break
5. Price is never the only factor
