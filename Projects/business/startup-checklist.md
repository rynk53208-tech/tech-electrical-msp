# Tech Business Startup Checklist

## First Week Tasks

### Foundation
- [ ] Register business name / DBA if needed
- [ ] Open business bank account
- [ ] Get EIN (IRS.gov, free, 5 min)
- [ ] Set up business phone number (Google Voice, Twilio, or RingCentral)
- [ ] Create business email (G Suite or Proton Mail)

### Legal & Compliance
- [ ] Choose business structure (LLC recommended for liability)
- [ ] File Articles of Organization with CA Secretary of State ($70)
- [ ] Get general liability insurance ($500-1000/yr)
- [ ] Check local business license requirements (Temecula/City of Riverside)

### Online Presence
- [ ] Claim Google Business Profile
- [ ] Set up simple website (single-page landing for now)
- [ ] Create LinkedIn company page
- [ ] List services on relevant directories (Angi, Thumbtack, Clutch for B2B)

---

## First Month Tasks

### Operations
- [ ] Define service offerings & pricing tiers
- [ ] Create basic service agreements/contracts
- [ ] Set up invoicing (Wave, QuickBooks Self-Employed, or Stripe)
- [ ] Set up accounting system (track expenses from day 1)

### Marketing
- [ ] Design basic business cards & flyers
- [ ] Set up Facebook/Instagram business pages
- [ ] Ask 3-5 satisfied customers for reviews
- [ ] Reach out to 10 potential referral partners (local electricians, Realtors, property managers)

### Systems
- [ ] Set up CRM or client tracking spreadsheet
- [ ] CreateStandard operating procedures (SOPs) for common services
- [ ] Set up remote access tools for MSP services (TeamViewer, AnyDesk, or Splashtop)
- [ ] Document hardware/software inventory system

---

## First Quarter Tasks

### Growth
- [ ] Land first 5-10 paid clients
- [ ] Build 3-5 case studies/testimonials
- [ ] Attend 2-3 local networking events
- [ ] Launch referral program for existing clients

### Credibility
- [ ] Pursue relevant certifications (CompTIA, Cisco, manufacturer certs for hardware)
- [ ] Get cybersecurity-specific insurance (E&O policy)
- [ ] Build out professional website with service pages & blog
- [ ] List on Upwork/Fiverr for initial project flow (build portfolio)

### Infrastructure
- [ ] Set up ticketing system (Zammad, SpiceWorks, or Paid - ConnectWise alternative)
- [ ] Establish vendor relationships (wholesale parts suppliers, drop-shipping)
- [ ] Create onboarding checklist for new clients
- [ ] Set up automated invoicing & follow-ups

| N-able / SolarWinds | Backup & monitoring | Tiered |

| Tool | Purpose | Cost |

| Tool | Purpose |
|------|---------|

| External NVMe/SSD dock | Data recovery |

## Quick Wins (Do These First)

1. **Google Business Profile** — free, shows up in local searches
2. **Referrals from friends/family** — lowest cost acquisition
3. **One-pager website** — establishes legitimacy
4. **Google Voice number** — looks professional, separates work/personal
5. **Basic liability insurance** — required for most commercial clients
