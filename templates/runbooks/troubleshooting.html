Common Issues Guide — Troubleshooting Runbook

Format: simple, scannable steps for field techs. Each issue includes a quick checklist, common causes, resolution steps, and escalation guidance.

1) Slow network diagnosis

  1. Check physical Layer: link lights, cables, Wi‑Fi signal strength.
  2. Verify IP connectivity: ping default gateway and 8.8.8.8.
  3. Test bandwidth: speedtest to local ISP gateway.
  4. Examine device rate limits, QoS, and VPN tunnels for congestion.
  5. Check for background updates or large transfers.

Common causes: network congestion, faulty cabling, bad Wi‑Fi, router/switch issues, ISP outage.

Resolution: reseat cables, reconnect Wi‑Fi, reboot router, check for RPM/firmware updates, run traceroute, contact ISP if needed.

When to escalate: persistent degradation beyond 30 min, suspected ISP outage, or hardware fault on core device.

2) Printer not connecting

  1. Confirm printer is powered on and on the network.
  2. Ping printer IP or hostname; verify driver configuration on client.
  3. Check print queue for stuck jobs; clear or cancel if needed.
  4. Reinstall/update printer driver; verify share/ACLs if networked.
  5. Test from another device to isolate client issue.

Common causes: offline printer, wrong IP, driver mismatch, driver cache corruption, firewall blocks.

Resolution: set static IP if DHCP churns, update drivers, restart printer spooler, reboot client, check firewall rules.

When to escalate: printer hardware fault, ongoing network ACL issues, or multiple users affected.

3) VPN won’t connect

  1. Validate credentials and VPN service status.
  2. Check network reachability to VPN gateway (ping, traceroute).
  3. Verify client config (server address, port, protocol, TLS/ certs).
  4. Review logs for failure codes; reset or reissue tokens/certs if needed.
  5. Test fallback: connect from another network or device.

Common causes: expired certs, token, license issues, firewall blocking, DNS split tunneling.

Resolution: renew certs/token, adjust firewall, reset VPN service, reinstall client, update to latest client.

When to escalate: repeated failures after config verified, or gateway unreachable from multiple networks.

4) Email not working

  1. Check service status and account credentials.
  2. Ping mail server and verify DNS MX records.
  3. Test sending/receiving from another client or webmail.
  4. Check for large mailboxes, phishing rules, or transport rules.
  5. Review spam/junk routing and autopurge settings.

Common causes: credential issues, DNS problems, server outages, large attachments, misconfigured rules.

Resolution: reset password, reconfigure account, fix DNS, clear local cache, check quotas.

When to escalate: provider outage, domain-wide DNS changes, or security/compliance blocks.

5) Computer running slow

  1. Open Task Manager/Activity Monitor; check CPU/memory/disk usage.
  2. Identify startup programs; disable unnecessary items.
  3. Run disk cleanup and check for malware; scan with updated AV.
  4. Check for drive health (S.M.A.R.T.), fragmentation, and updates.
  5. Ensure latest OS and driver updates; reboot.

Common causes: background processes, malware, full disk, aging hardware, overheating.

Resolution: end resource hogs, upgrade hardware if needed, refresh OS, clean temp files.

When to escalate: persistent slowness after cleanup, suspected malware, or hardware failure symptoms.

6) Can't access shared drive

  1. Verify network connectivity to file server.
  2. Confirm credentials and mount path; check permissions.
  3. Test with IP address; map drive again; check for DNS issues.
  4. Check server availability and share permissions.
  5. Review VPN if remote access is required.

Common causes: permissions, offline server, DNS resolution, expired credentials, network segmentation.

Resolution: re-map drive, update credentials, verify share permissions, restart client services, check firewall.

When to escalate: server-side outage, ACL misconfig, or widespread access failures.
