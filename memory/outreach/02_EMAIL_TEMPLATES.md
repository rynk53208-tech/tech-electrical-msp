## Template Customization Guide

### By Industry

**Medical Offices / Dental Clinics:**
- Lead with: HIPAA compliance + cyber risk
- Angle: Patient data = liability + cost
- Call to action: "Free compliance audit"

**Retail Stores:**
- Lead with: POS system reliability + data breach costs
- Angle: Downtime = lost sales + chargebacks
- Call to action: "Free POS security check"

**Restaurants:**
- Lead with: Electrical + POS + uptime
- Angle: Kitchen goes down = $1,000+/hour lost
- Call to action: "Free infrastructure review"

**Auto Repair:**
- Lead with: Diagnostic equipment + uptime + electrical load
- Angle: Shop downtime = customer loss + revenue drop
- Call to action: "Free diagnostic network audit"

### Personalization Fields

Replace these in each email:
- `[NAME]` — recipient's first name
- `[TARGET INDUSTRY]` — medical/dental/retail/restaurant/auto repair
- `[PRACTICE TYPE]` — specific type (e.g., "dental practice," "repair shop")
- `[SPECIFIC INDUSTRY COMPLIANCE]` — HIPAA, PCI-DSS, OSHA, etc.
- `[COMPLIANCE REQUIREMENT]` — the specific reg they care about
- `[IRVIN NAME]` — Use "Irvin Avitia" or "Irvin" depending on tone
- `[SERVICE TYPE]` — MSP, cybersecurity, electrical, etc.

### Tone Notes

- **Template #1** = Conversational, low-pressure, curiosity-based
- **Template #2** = Credibility + value, medium urgency, specific offer
- **Template #3** = Deep insight, problem-centric, premium positioning

Choose based on prospect research—if they're already struggling, start with #2. If it's cold, start with #1.
