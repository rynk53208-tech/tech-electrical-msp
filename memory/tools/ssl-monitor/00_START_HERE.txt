🎯 WHAT IS THIS?

A single HTML file that tracks SSL certificate expiry dates across your domains.
Monitors 10+ domains, alerts you before expiry, exports reports in multiple formats.

✨ FEATURES:
- Dashboard with real-time statistics
- Add/edit/delete domains
- Expiry countdown with color-coded urgency
- Alert system (expired/expiring soon)
- Auto-check scheduling
- Export reports (CSV/JSON/HTML/PDF)
- Data backup/restore
- Works offline (no server needed)
- Responsive design (desktop/mobile)

1. Double-click: index.html

⚙️ KEY SETTINGS
================================================================================

Settings Tab → Alert Thresholds:
  • Critical: 7 days (red alert when expires in 7 days)
  • Warning: 30 days (yellow alert when expires in 30 days)

Settings Tab → Check Frequency:
  • Manual: Only when you click "Check All"
  • Daily: Automatic check every morning at 6 AM
  • Weekly: Check Monday morning
  • Monthly: Check 1st of month

Settings Tab → Data:
  • Export backup → Download JSON file
  • Import backup → Restore from saved file
  • Reset to demo → Reload sample data
  • Clear all → Delete everything

================================================================================
❓ FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Where is my data stored?
A: In browser localStorage (local storage on your computer). It's not uploaded anywhere.

Q: Will I lose my data if I close the browser?
A: No! Data persists. It stays until you clear it.

Q: Can multiple people use this?
A: Each user/computer gets their own data. Share via export/import JSON.

Q: Can I add more than 10 domains?
A: Yes! Unlimited domains supported. Add as many as you need.

Q: How do I backup my data?
A: Settings → "Export All Data" → Save the JSON file somewhere safe.

Q: How do I restore from backup?
A: Settings → "Import Data" → Select previously saved JSON file.

Q: Does this require a server?
A: No! Completely offline. Works without internet (except for initial load).

Q: What browser do I need?
A: Chrome, Firefox, Safari, or Edge (any modern browser).

Q: Can I print a report?
A: Yes! Reports tab → Generate Report → Print button or export as PDF.

Q: What if I find a bug?
A: Try resetting to demo first (Settings → "Reset to Demo").
  If that doesn't work, export your data, clear all data, reload tool.

Q: Can I share certificates with my team?
A: Yes! Export as CSV and email, or export JSON for system integration.
