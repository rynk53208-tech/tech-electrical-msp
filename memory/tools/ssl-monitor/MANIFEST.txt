QUICK START
===========

1. Open index.html in web browser
   - Double-click file → opens in default browser
   - Or: File menu → Open → select index.html
   - Works on Windows, Mac, Linux

2. View Dashboard
   - See 10 pre-loaded demo domains
   - Stats: 10 total, 7 valid, 1 expiring, 2 expired
   - Color-coded: Green (OK), Yellow (warning), Red (expired)

3. Explore Features
   - Dashboard tab: Overview & statistics
   - Domains tab: Full domain list + management
   - Alerts tab: Active alerts requiring action
   - Reports tab: Generate & export reports
   - Settings tab: Configure thresholds & schedule

4. Add Your Domains
   - Click "➕ Add Domain"
   - Enter domain name (e.g., example.com)
   - Click Save
   - Domain appears in list immediately

5. Monitor & Alert
   - Automatically alerts when domains expire
   - Configure thresholds: critical (7 days), warning (30 days)
   - View all alerts in Alerts tab

TROUBLESHOOTING
===============

Issue: Data not saving?
  → Check if localStorage is enabled (browser settings)
  → Try exporting data (test functionality)
  → Clear browser cache and reload

Issue: Can't add domain?
  → Verify domain name format (use lowercase)
  → Check if domain name is empty
  → Try clearing browser cache

Issue: Check always fails?
  → This is demo mode (simulated checks)
  → For real certificate checking, needs backend API
  → Review status indicators (color-coded)

Issue: Alerts not appearing?
  → Check Settings tab (verify alert thresholds)
  → Click "Check Alerts Now" to manually trigger
  → Verify notification toggles are enabled

Issue: Export not downloading?
  → Check popup/download settings in browser
  → Try different export format
  → Use different browser to test
