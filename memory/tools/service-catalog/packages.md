## Proposal Tips

1. **Lead with the package** — Don't itemize first. Present value, then break it down if they ask.
2. **Annual billing close** — "Pay annually and save ~$1,200" is a powerful anchor.
3. **Upsell at sign-up** — When closing Package 1, mention "most clients add our Camera Package within 6 months."
4. **Electrical angle** — When competing against MSP-only shops, highlight the integrated electrical. No one else offers this.
5. **Mission Critical close** — Show Package 3 first. It anchors price. Package 2 feels like a deal by comparison.
