# Overnight Knowledge Base - Research Plan

This document outlines 4 project ideas to develop knowledge base content overnight. Each idea includes the target audience, content outline, estimated effort, priority, and how it helps win/keep clients.

## 1) Client IT Issues FAQ (Common IT problems and quick fixes)

- Target audience: Small to mid-size business clients (non-technical stakeholders) and frontline support techs.
- Content outline:
  - Common categories: Network, Endpoint, Security, Cloud, Data backup, Access management
  - Top 20 frequent issues with symptoms, quick triage steps, and when to escalate
  - Glossary of terms, acronyms, and service SLAs
  - How-to checklists (phone/remote)
  - Do's and don'ts for end users
- Estimated effort: 6-10 hours
- Priority: High
- How it helps win/keep clients: Reduces time-to-resolution, lowers support friction, demonstrates competence and proactive support in onboarding materials, builds trust with clear expectations.

## 2) Tech Troubleshooting Runbooks for Field Techs

- Target audience: MSP/MSSP engineers and field technicians.
- Content outline:
  - Standardized playbooks for common scenarios: PC boot issues, network VPN, email config, printer issues, software deployment, patching
  - Step-by-step commands, verification checks, rollback steps
  - Troubleshooting flowcharts and escalation triggers
  - Tooling checklist (remote access, logging, pre/post checks)
- Estimated effort: 8-12 hours
- Priority: High
- How it helps win/keep clients: Ensures consistent service quality, reduces mean time to repair (MTTR), supports scalable onboarding of engineers, reduces ticket handoffs.

## 3) Vendor Comparison Docs (AV, Backup, Cloud)

- Target audience: IT leadership, procurement, and technical decision-makers.
- Content outline:
  - Criteria matrix (features, pricing, security, compliance, support, SLAs)
  - 3-5 vendors per category with strengths/weaknesses
  - Use-case fit and recommended purchases by client size
  - Negotiation tips and pilot/test plan templates
  - TCO/ROI calculators (basic)
- Estimated effort: 10-16 hours
- Priority: Medium-High
- How it helps win/keep clients: Provides a transparent framework for evaluating vendors, positions the team as credible advisors, accelerates procurement, reduces churn by aligning vendors to client needs.

## 4) Compliance Guides (HIPAA, PCI) for Clients

- Target audience: Compliance officers, IT managers, system admins in regulated industries.
- Content outline:
  - Regulatory overview, key controls, recent changes, and common misconfigurations
  - Role-based responsibilities and sampling checklists
  - Policy templates (data retention, access control, incident response, vendor management)
  - Assessment templates and remediation guidance
  - Quick-start roadmaps by industry (e.g., healthcare, retail, fintech)
- Estimated effort: 12-20 hours
- Priority: Medium
- How it helps win/keep clients: Positions the firm as regulatory-savvy partner, reduces risk for clients, supports sales by offering ready-to-use templates and structured compliance paths.

## 5) Security Policy Templates (Baseline security policies)

- Target audience: IT admins, security officers, MSP customers.
- Content outline:
  - Baseline policies: Acceptable Use, Password/Authentication, Endpoint Security, NetworkSegmentation, Incident Response, Data Handling, Third-party access
  - Policy templates with commentary, implementation steps, and measurement rubrics
  - Customization guidance by client size and industry
  - Update cadence and governance model
- Estimated effort: 6-12 hours
- Priority: Medium
- How it helps win/keep clients: Lowers client setup friction, demonstrates mature security posture, provides reusable assets across clients, and reduces legal/compliance risk concerns.

## Priority Ranking (1 = highest)
1. Client IT Issues FAQ
2. Tech Troubleshooting Runbooks
3. Vendor Comparison Docs
4. Compliance Guides (HIPAA, PCI)
5. Security Policy Templates

## How this work supports Irvin's goals
- Accelerates onboarding and reduces support cycle times, increasing client satisfaction and retention.
- Provides defensible, repeatable processes to scale operations and win new business.
- Delivers concrete assets (FAQs, runbooks, templates) that can be packaged into service offerings and proposals.
