## Usage Tips

- **Customize the brackets** — Every `[ ]` item needs client-specific details
- **Keep it consistent** — Use the same structure each reporting period for comparability
- **Be concise** — Clients prefer actionable summaries over walls of text
- **Highlight value** — Always connect technical work to business outcomes
- **Set expectations** — Define report delivery cadence in your service agreements
