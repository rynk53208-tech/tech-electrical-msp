# Client Communication Guide

> Irvin's Tech & Electrical Services

---

## 1. How to Answer the Phone

**Answer within 3 rings.**

**Script:**
> "Thanks for calling Irvin's Tech, this is [your name]. How can I help you?"

**Tips:**
- Speak clearly and with confidence
- Smile while talking — it comes through in your voice
- Be ready to handle questions or transfer to Irvin
- If Irvin's unavailable, offer to take a message or schedule a callback

---

## 2. Taking Messages

When a caller needs to reach Irvin or requires follow-up:

**Get the following info:**
- Caller's name
- Phone number (confirm it)
- Reason for call / brief summary
- Best time to call back
- Any urgency level

**Script:**
> "Can I get your name and number in case we get disconnected? I'll make sure Irvin gets this message."

**After the call:**
- Write it down clearly in the message log or shared doc
- Include timestamp
- Notify Irvin immediately if urgent

---

## 3. Handling Complaints

**Stay calm, professional, and empathetic.** Never argue.

**Steps:**
1. **Listen fully** — let them vent without interrupting
2. **Acknowledge** — "I understand why that's frustrating"
3. **Apologize** — even if not your fault, apologize for the experience
4. **Solve** — ask what would fix it, or offer solutions you can commit to
5. **Follow up** — confirm the fix and timeline

**Escalation:**
- If you can't resolve it, promise to have Irvin call them back — and make sure he does
- Never say "that's not my job" — redirect: "Let me get you to someone who can help"

---

## 4. After-Hours Protocol

**Business hours:** Monday–Friday, 8:00 AM – 6:00 PM (PST)

**After-hours handling:**
- Voicemail redirects to emergency line if applicable
- For non-emergencies: "We're currently closed. Leave a message and we'll return your call tomorrow."

**Emergency clause:**
- If it's a business-critical outage or security issue, note it as URGENT and text Irvin directly
- Define "emergency" clearly: data breach, complete system down, electrical hazard

**Never:**
- Promise same-day after-hours service without checking with Irvin first
- Give out personal cell numbers unless authorized
