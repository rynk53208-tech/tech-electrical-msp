# Quick Fixes Guide

Quick troubleshooting for the most common tech issues. Try these steps in order before calling for help.

---

## 1. Computer Won't Turn On

**Step 1: Check power cable**
- Is it plugged in firmly at both ends?
- Try a different outlet (test with a lamp or phone charger)
- Check the power strip/surge protector is on

**Step 2: Check monitor**
- Is the monitor powered on?
- Is the display cable secure?
- Try brightness/contrast knobs

**Step 3: Listen for signs of life**
- Fans spinning? Hard drive clicking?
- Any beeps? (count them — BIOS beeps indicate hardware issues)
- Any LED lights on the case or keyboard?

**Step 4: Disconnect peripherals**
- Unplug everything except power and monitor
- Try booting again

**Still nothing?** Could be dead PSU, failed motherboard, or power button issue. Time to dig deeper or bring it in.

## 2. No Internet Connection

**Step 1: Check the basics**
- Is Wi-Fi turned on? (laptop: Fn+airplane key, or click the icon)
- Ethernet cable plugged in?

**Step 2: Restart the设备**
- Turn off computer, wait 10 seconds, turn back on
- Unplug router/modem, wait 30 seconds, plug back in

**Step 3: Check other devices**
- Can your phone connect to the same Wi-Fi?
- Can other computers in the house get online?

**Step 4: Forget and reconnect (Wi-Fi)**
- Forget the network, then rejoin with the password

**Step 5: Run network troubleshooter**
- Windows: Settings → Network & Internet → Status → Network troubleshooter
- Mac: System Settings → Network → Assist Me

**Step 6: Check IP config**
- Windows: Open CMD, type `ipconfig /release` then `ipconfig /renew`
- Mac: sudo ipconfig set en0 DHCP

## 3. Slow Computer

**Step 1: Check Task Manager (Windows) / Activity Monitor (Mac)**
- What's using the most CPU and memory?
- Close programs you don't need

**Step 2: Restart**
- Seriously — restart clears temp files and resets resources
- Try restarting once a week as maintenance

**Step 3: Check storage space**
- If drive is >90% full, that's your problem
- Delete unused programs, clear Downloads, empty Recycle Bin

**Step 4: Check for malware**
- Run a full scan with Windows Defender or your antivirus

**Step 5: Update OS and drivers**
- Windows Update or macOS Software Update
- Outdated drivers cause slowdowns

**Step 6: Browser too slow?**
- Clear cache/cookies
- Disable extensions you don't use
- Try a different browser temporarily

---

## 4. Printer Not Working

**Step 1: Check the basics**
- Printer powered on?
- Paper loaded?
- Ink/toner levels OK?

**Step 2: Check connections**
- USB cable secure? Or Wi-Fi connected?
- Try unplugging and replugging USB

**Step 3: Clear print queue**
- Windows: Settings → Bluetooth & devices → Printers → Open print queue → Cancel all
- Mac: System Settings → Printers → Clear queue

**Step 4: Set as default printer**
- Make sure the right printer is selected

**Step 5: Remove and re-add printer**
- Delete the printer, then re-add it

**Step 6: Run printer troubleshooter**
- Windows has a built-in troubleshooter in Settings

**Step 7: Check driver**
- Go to manufacturer's website, download latest driver for your model

## 5. Password Reset

**Windows (local account):**
1. On login screen, click "I forgot my password"
2. If you set security questions, answer them
3. Otherwise, you'll need a Windows install USB to reset

**Windows (Microsoft account):**
1. Go to account.microsoft.com → Sign in
2. Click "Forgot password"
3. Verify via email or SMS

**Mac:**
1. Turn off Mac, turn on holding Cmd+R
2. Select "Reset Password" from Utilities
3. Follow prompts (requires FileVault key or Apple ID if enabled)

**Browser / website:**
1. Click "Forgot Password" on the login page
2. Check email for reset link (also check spam)
3. Don't recognize the email? Ignore it — don't click

**Tips:**
- Use a password manager to avoid this
- Keep backup emails updated
- Write recovery codes somewhere safe
