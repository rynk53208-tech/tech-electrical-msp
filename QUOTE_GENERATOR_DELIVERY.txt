DATA PERSISTENCE
================================================================================

Browser localStorage:
  • tes_quotes       — Array of all quotes (client info, line items, status, etc.)
  • tes_reminders    — Reminder list (dates, priorities, done status)
  • tes_services     — Service catalog (50+ services, editable)
  • tes_settings     — Company info, rates, PDF preferences

Advantages:
  ✅ Works offline (no server, no cloud)
  ✅ Fast (all local, no network latency)
  ✅ Private (data stays on your device)
  ✅ No subscription/recurring fees

Limitations:
  ⚠️  Per-browser (Chrome ≠ Firefox)
  ⚠️  Per-device (laptop ≠ desktop)
  ⚠️  Storage limit: ~5-10MB (~150 quotes max)
  ⚠️  Backup required (use JSON export)

================================================================================
TECHNICAL STACK
================================================================================

• Vanilla JavaScript (ES6)
• HTML5 (Canvas for signature capture)
• CSS3 (Dark cyber theme, dark neutral palette)
• jsPDF v2.5.1 (CDN) for PDF generation
• jsPDF autoTable v3.8.2 (CDN) for table layout
• Browser localStorage (native API)

No build step, no npm, no server required. Single HTML file that works in any modern browser.

HOW TO DEPLOY
================================================================================

Option A: Local File (Simplest)
  1. Copy quote-generator.html to your computer
  2. Double-click to open in browser
  3. Bookmark for quick access
  4. Start using

Option B: Shared Drive (For Teams)
  1. Copy to network shared folder
  2. Create shortcut on team desktops
  3. Team opens from shortcut
  4. Each browser has independent data (use JSON export to sync)

Option C: Dropbox / Google Drive (Cloud Backup)
  1. Upload to cloud storage
  2. Share link with team
  3. Open from browser
  4. Data persists locally

Option D: Web Server (Advanced)
  1. Upload to internal web server (nginx, Apache, IIS)
  2. Access via URL (https://company-internal.com/quote-generator.html)
  3. Requires server setup, but always latest version
