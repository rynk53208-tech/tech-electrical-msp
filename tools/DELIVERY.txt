HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: DEMO MODE (No Setup Required)
────────────────────────────────────────
  1. Open: /root/.openclaw/workspace/tools/network-mapper.html
  2. Click: "Demo Data" button
  3. View: Instant topology visualization of Barney's network

OPTION 2: REAL NETWORK SCANNING
────────────────────────────────
  1. Install:  pip3 install flask flask-cors
  2. Start:    python3 /root/.openclaw/workspace/tools/network-scanner.py
  3. Open:     /root/.openclaw/workspace/tools/network-mapper.html
  4. Enter:    Your subnet (e.g., 192.168.1.0/24)
  5. Scan:     Click "Scan Network" button
  6. Wait:     10-30 seconds for results
  7. View:     Results in topology & table

TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════════

Frontend:
  • HTML5 + CSS3 + JavaScript (ES6)
  • Mermaid.js for diagrams
  • Fetch API for backend communication
  • No frameworks or build process needed

Backend:
