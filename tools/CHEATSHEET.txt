🚀 QUICK START (30 SECONDS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Demo Mode (No Setup):
  1. open /root/.openclaw/workspace/tools/network-mapper.html
  2. Click "Demo Data" button
  3. See Barney's Tire Shop network topology

Real Scanning:
  1. pip3 install flask flask-cors
  2. python3 /root/.openclaw/workspace/tools/network-scanner.py
  3. open /root/.openclaw/workspace/tools/network-mapper.html
  4. Enter subnet: 192.168.1.0/24
  5. Click "Scan Network"
  6. Wait 10-30 seconds

💻 KEY COMMANDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Start Backend:
  $ python3 /root/.openclaw/workspace/tools/network-scanner.py
  or with root:
  $ sudo python3 /root/.openclaw/workspace/tools/network-scanner.py

Check Backend Status:
  $ curl http://localhost:5000/api/status

Open Frontend:
  $ open /root/.openclaw/workspace/tools/network-mapper.html

Run Tests:
  $ /root/.openclaw/workspace/tools/test-network-mapper.sh

Kill Backend (if stuck):
  $ sudo kill -9 $(sudo lsof -t -i :5000)

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem              | Solution
─────────────────────┼──────────────────────────────────────────────────
"No module Flask"    | pip3 install flask flask-cors
Port 5000 in use     | sudo kill -9 $(sudo lsof -t -i :5000)
No hosts found       | Try /25 instead of /24, or use --deep mode
"Connection refused" | Backend not running, start with command above
Scan too slow        | Use smaller subnet (/25 or /26)
Browser won't load   | Use Chrome, Firefox, Safari, or Edge

🔒 SECURITY NOTES

⚠️  Only scan networks you own or have permission to scan!

• No data is sent to external servers
• All results stay on your local machine
• Standard network discovery (ICMP, ARP)
• May trigger IDS/IPS if misconfigured
• Use in trusted network environments only
